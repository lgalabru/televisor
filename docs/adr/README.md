# Architecture decision records

One file per decision a newcomer would question: a choice between real
alternatives, a reversal, a study that changed a choice. Records are
never rewritten; a new one supersedes an old one.

```
# ADR NNNN: <the decision, as a sentence>

Status: proposed | accepted (YYYY-MM-DD) | superseded by NNNN | rejected

## Context       what was true, what we knew, what forced a choice
## Decision      what we do, present tense
## Consequences  what it costs, rules out, makes easy
## Possible future improvements   optional
## References    optional
```
