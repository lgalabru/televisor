# Requests for discussion

Ideas before they are decisions: allowed to be rough, never vague about the
question they ask. When one settles, its decision moves to an ADR.

```
# RFD NNNN: <title>

State: idea | discussion | parked | adopted (ADR NNNN) | abandoned
Authors: <who>  ·  Started: YYYY-MM-DD

## Problem          what hurts, who it hurts, how we know
## Sketch           the idea, as concrete as possible
## Open questions   each with how we'd find out
## Risks            what could make this a bad idea
## What we learned  appended, dated, newest last
```
